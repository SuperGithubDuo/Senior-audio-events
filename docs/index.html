Against your annotations

Load an annotations CSV to see which events were found, false alerts and how quickly each was raised (±1 s matching, as in evaluate).

Scores come from YAMNet running in TensorFlow.js. For files already at 16 kHz they match the Python detect command closely; other sample rates are resampled by the browser, so small differences are expected. Use the Python evaluate command on held-out recordings for numbers you report. Browser audio processing (echo cancellation, noise suppression, auto gain) is turned off for the microphone.
